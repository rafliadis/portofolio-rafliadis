Halo! Saya Rafli Adi Septiyan, mahasiswa semester 7 S1 Informatika di Universitas Bina Sarana Informatika (UBSI). Saya memiliki ketertarikan mendalam pada rekayasa perangkat lunak menyeluruh, mulai dari perancangan arsitektur basis data, pengembangan API dan aplikasi web interaktif, hingga implementasi kecerdasan buatan.

Dalam praktik pengembangan web, saya terbiasa memanfaatkan ekosistem PHP dengan Laravel dan CodeIgniter 4, dipadukan dengan Tailwind CSS untuk tampilan modern. Di ranah mobile, saya menggunakan Flutter & Dart. Sementara untuk kecerdasan buatan dan analisis data, saya mengeksplorasi Python, TensorFlow, OpenCV, dan Streamlit.
